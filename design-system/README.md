# Crooked concept design system

Unofficial design exploration. Not affiliated with, endorsed by or connected to Crooked Media.

- `index.html`: browsable design system (open locally or via the Netlify deploy).
- `Crooked-Concept-Brand-Book.pdf`: the printable reference book.
- `tokens.json` / `tokens.css` / `bundle.css`: tokens and component styles.
- `components/`: live previews of each component and collateral piece.
- `assets/`: merch, hat and Round 2 poster mockups.
- `source/`: the brand book text (Markdown), tokens and component guidelines this site is built from.
- `tools/`: the scripts that generate the site and the PDF.
