# Chip

Pill filters for the show grid.

**Provide:** `<button class="ck-chip">` with `aria-pressed` set; the selected state is driven by `aria-pressed="true"`.

- Filter only. Never use a chip as a link or a tag that does nothing.
- Selected: `chip-selected-bg` with `chip-selected-fg` (navy and yellow in light; slate and navy in dark).
- Labels are short nouns in sentence case: "Daily news", "Law & courts".
