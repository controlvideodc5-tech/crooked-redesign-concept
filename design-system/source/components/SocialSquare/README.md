- Headline `display-poster` at 178–220px. Fit by size, never by squeezing tracking.
- Grounds: navy (default), yellow, chrome (for chat and app formats), pink (reproductive freedom), paper (comparisons), red (labor and display-only pieces; white or cream type at display size only, since white on red is 4.2:1).
- Footer mono line credits the show that covers the topic (Pod Save America, Strict Scrutiny, What A Day) or restates the system line.
- In chat-format posts, the friend's yellow bubble carries the turn toward action; lowercase and emoji belong to the quoted voices only.
