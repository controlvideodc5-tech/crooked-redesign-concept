# StickerSheet

Die-cut stickers: one slogan each, display type only.

**Provide:** a slogan of two to six words; a shape (circle 320, burst 340, rounded rect 340×200 at 24px radius, oval 360×230); a ground and ink pair from the list below.

| Ground | Ink | Ratio |
| --- | --- | --- |
| `c-yellow-500` | `c-navy-900` | 11.8:1 |
| `c-navy-900` | `c-yellow-500` | 11.8:1 |
| `c-pink-300` | `c-navy-900` | 10.1:1 |
| `c-chrome-950` | `c-yellow-500` | 13.5:1 |
| `c-white` + 6px navy rule | `c-navy-900` | 16.9:1 |
| `c-red-500` | `c-white` | 4.2:1, display size only |
| `c-sky-600` | `c-cream-100` | 4.1:1, display size only (the one sky use outside Con) |

- 10px white kiss-cut border on every shape.
- Bursts carry the loudest lines ("Down, not out", "Less doom. More doing.").
- Slogans come from the house lines in the voice section; no new jokes on stickers without a second read.
