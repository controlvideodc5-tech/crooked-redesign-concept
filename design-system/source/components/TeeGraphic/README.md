# TeeGraphic

Print-ready garment art on a 1400×1400 artboard, shown at 30%.

**Provide:** a seal line in mono (the joke), the display lockup (the claim), and a mono credit line ("Crooked · Department of …").

- The seal: a dashed `c-yellow-500` ring (r 430, 2/22 dash, 60%) around a solid `c-navy-400` ring (r 360).
- Display at 150px in yellow; mono lines 22px, tracking .1em.
- Two-color screen print where possible (yellow + white on navy). Garment color carries the ground.
