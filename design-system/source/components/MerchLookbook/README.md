# MerchLookbook

The merch lookbook: fourteen products, each carrying one house line.

**Provide:** a house line, a garment and color, the print method and inks, and a mockup caption (PRODUCT NAME over a mono spec line). The rules are in **MerchLine**.

- Lines used: Show up U.S. tour '26, Crooked says relax, Relax. Don't doom it. Do it., Listen. Show up. Organize., Doomscroll less. Doorknock more., Hope is a verb, Less doom. More doing., Touch grass. Then protect it., The news, minus the panic, Hot takes. Cool planet., Ballot first. Brunch after., Down, not out, Phone bank > fear bank, Turn out, not off.
