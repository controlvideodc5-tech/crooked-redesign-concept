# HatSeries

Everybody In: six hats, one idea, plus a 3:1 series banner.

**Provide:** one shared idea, one line per hat that restates it, a hat style per line (cap, trucker, beanie), and a twill or knit color with one embroidery or patch color.

- Lines: Everybody in · Raise the floor · Everybody eats · Working people first · All of us · Build it here.
- Banner: navy ground, yellow display headline, one row of hat tiles, one line of body ("Six hats, one idea…").
- Source images: asset group **Everybody In Hats**, rendered from the hats PDF.
