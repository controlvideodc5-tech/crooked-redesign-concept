# UnofficialMark

The line that keeps every piece honest about what it is.

**Provide:** `<span class="ck-unofficial">` placed in a corner or footer of every page, poster, social post, sticker sheet and merch mockup.

- Full form: "Unofficial concept · Not affiliated with Crooked Media". Short form on 1080² socials: "Unofficial concept".
- 11px Plex Mono at 55–60% opacity in the piece's own text color. Never removed, never hidden under art.
- The typeset "CROOKED" in Big Shoulders is a stand-in, not the official wordmark. Production work must use Crooked Media's own files and approval.
