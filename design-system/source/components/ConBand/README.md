# ConBand

The Crooked Con sub-brand: daytime sky, cream and butter type, navy hardware.

**Provide:** dates and city (eyebrow), the event line, a countdown (days, hours, minutes), and one ink button.

- Gradient `con-sky-top` → `con-sky-mid` → `con-sky-low`, closed by a 3px `con-rule`.
- All type sits in the top two-thirds, or on navy hardware like the countdown (`con-clock-bg`, `con-clock-fg`). Butter or cream over `con-sky-low` fails (2.4–2.7:1).
- Buttons on sky are ink, never yellow.
- Sky colors never leave Con placements. Use the official event art for the eagle and clouds.
- Keep ticket copy current: the concept's "Early-bird ends Oct 6" line is past due.
