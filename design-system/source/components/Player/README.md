# Player

The persistent audio player.

**Provide:** current show, episode title, elapsed time and progress (0–100%).

- Chrome (`bg-chrome`), not navy, so it reads as a tool. Metadata `fg-on-chrome-muted`; progress fill `accent-default`.
- Floats bottom-left on desktop (`z-dock`, `shadow-lift`); docks full width under 700px.
- Microcopy stays literal: "Up next", "Saved", "Paused".
