# EmailBanner

Newsletter header, 1200×600 (2:1), shown at 50%.

**Provide:** the newsletter name and moment as the eyebrow, a two-beat count headline in yellow, one sentence that promises exactly what's inside, and a single object on the right (calendar, ticket, receipt) that carries the date or number.

- Navy ground, halo pattern bottom-right, 70px padding, 1.3 : 1 split.
- The object is white with a red header strip and `shadow-art`; its number is display type.
- Body copy `c-slate-200` at 30px. Keep it to one sentence.
- Live text in the email body must repeat the headline; never put the only copy of a date inside an image.

- Count copy expires daily. As of Oct 30, 2026 the header reads "Four days. Every vote." Update or retire it after Nov 3.
