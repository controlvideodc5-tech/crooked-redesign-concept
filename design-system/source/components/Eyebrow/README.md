# Eyebrow

Mono caps metadata above a headline.

**Provide:** `<span class="ck-eyebrow">` with facts only: show names, durations, dates, counts.

- Style `eyebrow`: IBM Plex Mono 500, 12px, tracking `f-track-label`, color `fg-muted` (or `fg-on-inverse-muted` on navy).
- Separate facts with a middle dot; ranges take an en dash: `Nov 5–7 · Washington, DC`.
- One eyebrow per block and only when it adds a fact. Never on every card by habit.
