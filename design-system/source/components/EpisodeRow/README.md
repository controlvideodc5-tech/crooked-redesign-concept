# EpisodeRow

One episode in today's lineup: play, show, title, length.

**Provide:** show name (eyebrow), episode title (`title` style), duration in `mm:ss`, and a play button with an `aria-label`.

- Lives on `bg-inverse`; the row is `bg-inverse-raised` with `border-inverse`, radius `radius-xl`.
- Durations use tabular numerals in mono.
- Titles are the episode's real title, sentence case, no clickbait additions.
